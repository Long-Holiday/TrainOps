# TrainOps

保留原角色，交办任务才操作。设 `CLI="python3 <本目录>/scripts/trainops.py -p <实验项目目录>"`（`-p` 指实验项目）。**"不建表、不启动进程"只约束加载阶段**；**收到任务后按开工顺序执行**。

## 开工顺序

1. **计划**：`show --brief`；无计划时按目标、验收与授权范围建表（见 [CLI](references/cli.md)），耗时、依赖不定就留待估；已有计划先核实、不覆盖。
2. **面板**：随即以后台常驻任务起 `$CLI serve --port 8765 --interval 30`（顺带结算；别用 `&` 或前台），报出地址 http://127.0.0.1:8765。端口占用说明面板已在跑。
3. **无卡准备**：默认先 `power_on_no_gpu` 了解项目、配环境、改代码，就绪关机再申请有卡；除非用户要求持续请求或已核实无需准备，才直接 `power_on`。**不交付空等 GPU**，不支持无卡时说明限制。
4. **日志与训练**：按[实验日志](references/experiments.md) `experiment init` 复用指定/已有表，未指定则自动创建；核实 GPU 后启动，`experiment start` 登记 Run。

## 自主调度

以用户目标、验收标准和明确硬约束为准，按真实依赖、资源、成本、耗时与实验结果自主优化调度：重排、拆并任务、调整实例，先验证高风险环节，避免 GPU 空等和重复实验；不必逐项请示，用 CLI 同步并简述原因。

用户可能提供多个 AutoDL 实例及对应 SSH 名称，视为候选资源，不默认都有空闲 GPU。先核实实例与 SSH 映射、真实 GPU 可用性及已有任务，按依赖、GPU 型号/显存、环境与数据就绪情况、成本和预计耗时调整顺序、并行度与实例分配。某台暂时缺卡时，优先用已就绪且满足要求的实例推进可执行实验，并完成无需 GPU 的准备，不让单台缺卡阻塞整个计划；资源变化后继续重排。迁移前核实环境、数据与 checkpoint 兼容性，不重复启动、不擅自中断已有训练；SSH 可达或开机请求已提交不代表 GPU 就绪，验证后才训练并标记 running。缺卡等待按已授权范围执行，不反复提交开机请求，超出约定范围先确认；同步实际分配、阻塞原因与待估耗时，不把等待伪装成运行进度。

不为提速绕过依赖或降低验收。冗余、失效或低收益任务可提替代方案；改变目标、放弃用户要求的实验、增加未授权费用或中断任务，先确认。见 [调度决策](references/cli.md#调度决策)。

## 安全边界

- 计划账本 `$PROJECT/.agent/experiment.yaml` 的 `plan` 段是唯一事实来源，只经 CLI 与面板时价修改：禁止直接 Edit/Write JSON/YAML、不覆盖已有计划；恢复先核实，不盲目重启。
- 编号固定：实例 `I01`、流程 `F01`、任务 `F01-T01`。计划只记任务名、实例、耗时、依赖、状态与进度；命令、日志、commit 留远端，详情另记。
- 同一 GPU 只跑一个任务，`local` 可并行；依赖未完成不得启动。done 前核实进程退出与产物；关机须用户授权，最终关机须无后续复用（开工顺序 3 与自愈止付除外）。
- 故障：先报告现象与已核实证据，再自愈（先定位原因、一次改一个变量、不重复同一动作），最多 5 次；仍无法继续即先关机止付（已预授权，属中间关机，见协议），任务记 `failed`/`blocked`、不标 done，随后报告等决策。
- 代码/环境放系统盘，数据/checkpoint/TensorBoard 放 `/root/autodl-tmp`，长期产物放 `/root/autodl-fs`（文件存储对所有实例共享，跨实例交接走它，各自分目录别撞名）；数据盘不随镜像保存，释放即丢，释放前先转存。
- 缺进度、耗时、费率或余额就保留待估，不猜数字、不补 0；可用时长只算现金、代金券另列；开机模式用 `--mode` 记，费率与 Token 在面板登记。

## 日常闭环

- 状态流转：`show --brief` → `set <任务> --status running` → `--progress 40`（真实观测）或 `--checked` → `done`，带 `--brief`
- 结构调整见 [CLI](references/cli.md)：`--brief` 结构编辑附检查，问题须修、提醒须判读，不撤销编辑；纯状态更新后不必再跑 check + show。
- 每 30 分钟 SSH 巡检（用户另定则遵从）；`--checked` 只记巡检时间、超 1 小时未记即未巡检；摘要注明省略数，按需 show/check 看全量。
- 巡检与完成/失败后 `experiment update`，并 `experiment sync` 补录；飞书失败不阻断训练与止付。
- 配置见 [AutoDL](references/autodl.md)，异常见 [协议](references/protocol.md)。结算由面板进程负责（余额与凭据不归你管），别另起常驻结算进程。
